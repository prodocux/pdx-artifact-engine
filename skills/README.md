# Skills

Skills are deterministic artifact executors called by PDX experts.

This directory will contain wrappers and metadata for:

- ProDocuX document skills
- FreeCAD CAD skills
- Blender scene and render skills
- chart, slide, image, video, code, and data skills

Each skill should provide:

- CLI entry point
- Python API where practical
- JSON schema input/output
- structured errors
- artifact manifest output
- verification hooks
- MCP wrapper metadata
