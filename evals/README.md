# Evaluations

PDX Artifact Engine should be evaluated as a runtime, not only as a language
model.

Core metrics:

- valid JSON rate
- tool selection accuracy
- expert routing accuracy
- missing-input detection
- source hallucination rate
- repair-loop success
- artifact verification pass rate
- RAM usage
- latency

3D metrics:

- FreeCAD vs Blender selection accuracy
- valid `pdx_3d_spec_v0` rate
- units and constraints present
- export success
- render nonblank check
