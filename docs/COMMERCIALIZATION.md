# Commercialization Notes

## Positioning

PDX Artifact Engine should not be positioned as a model vendor.

Better positioning:

> A local artifact engine that turns intent into verifiable deliverables using
> small agents and deterministic skills.

First wedge:

> Audit-ready regulatory document workflows for brands, labs, and consultants.

## Open Source Boundary

Open source:

- runtime contracts
- core skill wrappers
- basic CLI
- basic ProDocuX workflow examples
- Kaggle training notebooks
- evaluation harness

Paid:

- certified workflow packs
- jurisdiction rules
- golden tests
- validation reports
- enterprise connectors
- dashboard
- support
- on-prem appliance

## Why Open Source Helps

Regulated users need trust. Open source helps with:

- auditability
- adoption
- SEO
- developer trust
- partner integrations
- reproducibility

Revenue should come from verified delivery and operational responsibility, not
from hiding all code.
