# Public documentation policy

This repository uses an allowlist-oriented documentation boundary.

Public documentation may describe installation, supported APIs and contracts,
architecture, security policy, data handling, licensing, contribution, and
finalized release facts. It must remain product-neutral and portable.

The public tree must not contain commercial strategy, competition material,
internal review prompts, consumer-specific coordination, unpublished candidate
evidence, local absolute paths, credentials, customer data, or private binary
artifacts. Development and release coordination records are maintained outside
this public repository.
