# PDX Artifact Engine 0.3.0a9 candidate

Status: unpublished working tree. Do not use as a package pin.

This additive candidate introduces `pdx_provenance_bundle_v1`, a bounded,
digest-bound export of entities, activities, agents, and PROV-O-aligned
relationships. Durable Engine receipts remain authoritative.

The repository also contains a separately packaged, disabled-by-default
OfficeCLI adapter prototype at `0.1.0a1`. It is not included in the Engine
wheel and is not registered as a default executor. No OfficeCLI binary is
redistributed.

RoadStar scheduling and Farpals realignment are planning backlogs only. This
candidate does not authorize scheduling, Host Gate, Semantica, or OfficeCLI
production integration.
