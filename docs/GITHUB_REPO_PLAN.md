# GitHub Repository Plan

## Recommended Repository

Initial public repository:

```text
github.com/prodocux/pdx-artifact-engine
```

Alternative if the organization is not ready:

```text
github.com/<founder>/pdx-artifact-engine
```

## Repository Role

GitHub is the source of truth:

- architecture
- schemas
- examples
- issues
- releases
- skill wrappers
- model cards
- training notebooks
- benchmark results

Agent marketplaces, MCP registries, Kaggle, Hugging Face, PyPI, and Docker are
distribution channels. They should point back to GitHub.

## Suggested Visibility

Start public for:

- README
- schemas
- sample skill wrappers
- ProDocuX integration notes
- Kaggle notebooks
- small synthetic examples

Keep private or paid for:

- certified regulatory packs
- jurisdiction rule databases
- customer datasets
- commercial templates
- golden evaluation suites
- enterprise deployment scripts
